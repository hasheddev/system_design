Gathering requirements

Naive asking client to determine what they need.

Methodical way is through use cases and user flow
Use case is a scenario in which our system is used
User flow is a step by step / graphical representation of each use case

- Identify all actors/users in a system
- Capture and describe all possibe use cases / scenarios
- Take each use case and expand through flow of events
events contains action and data

Example
Allow people to join drivers on a route, who are willing to take passengers for a fee
actors are driver and passenger(rider)
use cases include 
- registeration by rider(first time)
- registeration by driver
- rider login
- rider logs in
- successful match and ride
- unsuccessful ride
