Lambda architecture was coined by nathan marz based on his experience working on big data, it attempts to find a balance between low latency from real time processing and high fault tolerance and comprehensiveness from batch processing
There are 3 layers
Batched, speed layer and serving layer
Data is dispatched into both batch and speed layers.

Batched layer is similar to batch processing and manages datasets and is a system of records that uses distributed file system designed to store bu files containing massive amount of data
It precomputes batched view it indexes and overwirtes precomputed views in read only database previously created. It aims at perfect accuracy

Speed layer uses realtime processing startegy with a message broker processing new event and adds record to real time view
It perates only on most recent data

Sercing layer esponds to queries and merges data from batch layer and real time views
