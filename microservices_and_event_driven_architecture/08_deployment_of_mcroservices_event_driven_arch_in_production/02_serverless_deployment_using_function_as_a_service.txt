Live events happen occasionally we may sell cheap tickets more than expensive tickets and if we do not sell tickets all the time
but get spikes for sale we pay for idle time and load balancer and autoscaling.
- For a digital advertisement company that provides insight into adverts, and it is nto cost efficient as requests might be spikes per month or quarter
This costs money when during other months or days the request are not made to the service

FaaS allows us to architect system in event driven mode from software to infrastructure, we provide events to handle and logic to execute the event and only when event is triggered is code deployed and code run 
If traffic is seasonal provider handles scalability for traffic spikes
Pricing mode is based on request number, time and memory to handle request but we do not pay when event do not happen
